## Как начать работу (для студентов)

1. **Создайте свой репозиторий из шаблона.** На странице шаблона нажмите **Use this template → Create a new repository**. Название: `pm-lab-<номер варианта>-<название проекта>`, например `pm-lab-00-aquamap`. Видимость: Private.
2. **Добавьте участников.** Settings → Collaborators → Add people. Добавьте всех членов группы и преподавателя.
3. **Подготовьте трекер одним нажатием.** Откройте вкладку **Actions → Bootstrap: метки, этап и стартовые задачи → Run workflow**. Через минуту в репозитории появятся метки, этап «ЛР1: Инициация» и 13 стартовых задач. Назначьте на них исполнителей.
   - Если вкладка Actions просит включить workflows, нажмите кнопку включения.
4. **Создайте доску.** Вкладка **Projects → New project → Board**. Колонки: `Backlog`, `To Do`, `In Progress`, `In Review`, `Done`. Добавьте в проект созданные задачи (в самой доске: Add item). Ссылку на доску вставьте в этот README.
5. **Заполните README.** Название, участники, роли, вариант.
6. **Работайте по заданию** [docs/tasks/lab-1-assignment.md](docs/tasks/lab-1-assignment.md).

## Правила работы

- Нет задачи в трекере, нет работы.
- Каждый документ попадает в `main` через Pull Request. В описании PR пишите `Closes #N`.
- Каждый участник должен быть и автором PR, и ревьюером.
- Если вы использовали ИИ-ассистента, запишите это в [docs/ai-usage.md](docs/ai-usage.md).
- Сообщения коммитов: `тип: описание (#N)`, например `docs: add stakeholder register (#5)`.
