## Как начать работу (для студентов)

1. **Создайте свой репозиторий из шаблона.** На странице шаблона нажмите **Use this template → Create a new repository**. Название: `pm-lab-<номер варианта>-<название проекта>`, например `pm-lab-00-aquamap`. Видимость: **Public**. На бесплатном тарифе GitHub защита ветки `main` работает только в публичных репозиториях. Поэтому не храните здесь пароли, ключи доступа и персональные данные.
2. **Добавьте участников.** Settings → Collaborators → Add people. Добавьте всех членов группы и преподавателя.
3. **Подготовьте трекер одним нажатием.** Откройте вкладку **Actions → Bootstrap: метки, этап и стартовые задачи → Run workflow**, выберите номер лабораторной работы (**1**) и нажмите **Run workflow**. Через минуту в репозитории появятся метки, этап «ЛР1: Инициация» и 13 стартовых задач. Назначьте на них исполнителей. В начале каждой следующей работы запускайте workflow снова с её номером.
   - Если вкладка Actions просит включить workflows, нажмите кнопку включения.
4. **Создайте доску.** Вкладка **Projects → New project → Board**. Колонки: `Backlog`, `To Do`, `In Progress`, `In Review`, `Done`. Добавьте в проект созданные задачи (в самой доске: Add item). Ссылку на доску вставьте в этот README.
5. **Заполните README.** Название, участники, роли, вариант.
6. **Работайте по заданию** текущей лабораторной из таблицы выше, начиная с [ЛР 1](docs/tasks/lab-1-assignment.md).
7. **Подтягивайте файлы новых работ из шаблона.** Команды приведены в шаге 0 каждого задания, начиная с ЛР 2.

## Правила работы

Подробно — в [CONTRIBUTING.md](CONTRIBUTING.md) (с ЛР 4).

- Нет задачи в трекере, нет работы.
- Каждое изменение попадает в `main` через Pull Request. В описании PR пишите `Closes #N`, у PR должна быть метка.
- Ветку создавайте из задачи и называйте `<тип>/<номер>-<кратко>`, например `feat/42-schools-300m`.
- Каждый участник должен быть и автором PR, и ревьюером. ИИ не может быть ревьюером.
- С ЛР 4 PR вливается, только когда автопроверка `ci / quality` зелёная и есть одобрение ревьюера. Ноутбуки сохраняйте без вывода ячеек.
- Если вы использовали ИИ-ассистента, запишите это в [docs/ai-usage.md](docs/ai-usage.md): сервис, модель, промпт, токены, как проверили ответ. Подробная инструкция и пример заполнения — в самом файле.
- Сообщения коммитов: `тип: описание (#N)`, например `docs: add stakeholder register (#5)`.
- Данные OpenStreetMap распространяются по лицензии ODbL: на картах и в отчётах указывайте «© участники OpenStreetMap» со ссылкой на <https://www.openstreetmap.org/copyright>.
