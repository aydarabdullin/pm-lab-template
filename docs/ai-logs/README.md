# Переписка с ИИ

Сюда можно складывать экспорт диалогов с ИИ-ассистентами, если сервис не даёт публичную ссылку на переписку. Один файл на запись журнала: `AI-03.md`, `AI-05.md` и т. д. Номер совпадает с ID записи в [docs/ai-usage.md](../ai-usage.md).

Перед сохранением уберите из переписки персональные данные, пароли и токены доступа.
